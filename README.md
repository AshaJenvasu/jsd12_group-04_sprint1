# 🎨 Creative Market - Group Project (Sprint 1)

Welcome to the first sprint of **Creative Market**, a collaborative web project developed by **Group 04** during the JSD12 Bootcamp. This platform is designed as a marketplace for digital art, music, and handmade crafts.

---

## 🚀 Sprint 1 Objectives
In this first iteration, our team focused on building a robust, responsive landing page using **Pure CSS** and **Semantic HTML**, ensuring a solid structural foundation before moving to dynamic frameworks.

### Key Milestones:
- **Modular Navigation**: A responsive header featuring desktop menus and mobile-optimized icons.
- **Hero Showcase**: High-impact "Hero Main" and "Hero Secondary" sections for featured products.
- **Content Organization**: Implementing "About Us", "Recommended Items", and "Artist Highlights" sections.
- **Pure CSS Layout**: Utilizing Flexbox and Grid without external frameworks to master layout logic.

## 📁 Repository Structure

- `index.html`: The main entry point combining all team-member components.
- `/styles`: Centralized CSS directory managing the "CSS Only" design policy.
- `/src`: Repository for SVG icons, product images, and branding assets.
